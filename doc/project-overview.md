# 프로젝트 개요

## 🎯 프로젝트 목적

**밥친구 (BapBuddy)**는 혼밥을 하기 싫어하는 사람들을 위한 위치 기반 밥친구 매칭 앱입니다.

### 핵심 가치
- **연결**: 혼밥하는 사람들을 연결
- **편의성**: 근처 1km 이내 사용자 매칭
- **관계**: 밥친구 온도 시스템을 통한 관계 관리
- **실시간**: 실시간 채팅 및 위치 공유

## 🚀 주요 기능

### 1. 사용자 관리
- 회원가입/로그인 (JWT 인증)
- 프로필 관리 (닉네임, 음식 취향, 프로필 이미지)
- 위치 기반 사용자 검색 (1km 이내)

### 2. 친구 시스템
- 근처 사용자에게 친구 요청
- 친구 요청 수락/거절
- 밥친구 온도 시스템 (0-100)
- 친구 목록 관리

### 3. 실시간 채팅
- 1:1 실시간 메시지 전송
- 텍스트, 이미지, 위치 공유
- 메시지 읽음 상태
- 채팅 시 온도 증가

### 4. 위치 서비스
- GPS 기반 위치 업데이트
- Haversine 공식을 이용한 거리 계산
- 근처 사용자 실시간 검색

## 🛠 기술 스택

### Frontend (Flutter)
- **Framework**: Flutter 3.x
- **Language**: Dart
- **State Management**: GetX
- **HTTP Client**: Dio
- **Real-time**: Socket.io Client
- **Maps**: Google Maps Flutter
- **Image**: Image Picker, Cached Network Image

### Backend (NestJS)
- **Framework**: NestJS (Node.js)
- **Language**: TypeScript
- **Database**: PostgreSQL
- **ORM**: TypeORM
- **Authentication**: JWT (Passport)
- **API Documentation**: Swagger/OpenAPI
- **Real-time**: Socket.io
- **Validation**: class-validator, class-transformer

## 📱 타겟 사용자

### 주요 사용자
- 혼밥을 하기 싫어하는 직장인
- 새로운 사람들과 만나고 싶은 대학생
- 같은 음식 취향을 가진 사람을 찾고 싶은 사람

### 사용 시나리오
1. **점심시간**: 회사 근처에서 밥친구 찾기
2. **저녁시간**: 새로운 사람들과 저녁 약속 잡기
3. **주말**: 같은 음식 취향을 가진 사람과 만나기
